# Screenshots

Screenshot-Studio – Web-App (PWA) fürs iPhone:

- Mehrere Screenshots zu einem Bild zusammenfügen (Scroll-Seite mit automatischer Überlappungs-Erkennung, untereinander, nebeneinander)
- Zuschneiden, Pfeil, Rahmen, Stift, Nummern, Text, Verpixeln
- Kundendaten automatisch verpixeln (IMEI, Telefonnummern, E-Mail – per Texterkennung, braucht Internet)
- Speichern über das iPhone-Teilen-Menü („Bild sichern“) als PNG oder JPG

Läuft über GitHub Pages: https://werkdoc.github.io/Screenshots/

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
